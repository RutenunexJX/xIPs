# xIPs application icon

Created with the built-in image generation tool (logo-brand), September 2026.
The coral front module and angular X identify xIPs. The stacked plates represent
reusable assets and explicit snapshots. Graphite and cyan tie the mark to the
AppSuite family while preserving xIPs' identity.

The generated PNG retains transparency. Qt smooth scaling produces the 32 px
and 256 px PNGs and the 16, 20, 24, 32, 48, 64, 128 and 256 px ICO frames.
No additional design edits were made during format conversion.

- `xips-icon-source.png`: original generated master.
- `xips.ico`: Windows executable, application and window icon.
- `xips-256.png`: AppSuite descriptor and ZeroSlack panel icon source.
- `xips-32.png`: compact preview.

The icon does not change shared success, warning, error, or selection colors.

## Final generation prompt
Use case: logo-brand. Asset type: production Windows desktop application icon for xIPs, a small AppSuite application for collecting reusable FPGA IP modules and immutable artifact snapshots. Create ONE finished icon, square 1024x1024, with a genuinely transparent exterior. A dark graphite rounded-square app tile, centered and filling about 88% of the canvas, with generous rounded corners. Within the tile, a bold highly legible geometric emblem: two subtly offset stacked module plates indicating saved snapshots, and a single prominent front module bearing an X formed from thick clean geometric strokes / negative space. Keep the silhouette simple enough to recognize at 16 and 32 pixels. The front module and X use warm coral-orange (#F58B72), with a restrained pale cyan (#89DCEB) accent on one rear layer. Tile graphite #202631, nearly flat with very subtle depth. Reference family style in words: ZeroSlack uses a cyan circuit-like Z on a dark rounded tile; Pinloom uses a teal and amber woven location mark. This new icon should belong beside them while clearly reading as a modular asset library. Precise symmetry and spacing, crisp clean vector-like edges, restrained professional engineering software identity. No wordmark or small text, no labels, no tiny circuit pins, no dots, no arrows, no gradients on the emblem, no glossy 3D extrusion, no busy circuitry, no decorative background, no mockup, no watermark. Only the finished application icon, with real alpha outside the tile.
